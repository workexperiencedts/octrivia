# Octrivia

A one-file pixel-art arcade trivia game. Play it free in your browser:
**https://workexperiencedts.github.io/octrivia/**

Works on computers, phones and iPads. Single-player only in this copy.

- **Phone or iPad held upright:** the clue and a big button for each barrel appear under the screen. Tap one to shoot it.
- **Held sideways / computer:** tap or click a barrel (or its name sign) to shoot it. On a keyboard, keys 1-8 pick a barrel.
- **PAUSE** opens a menu with Resume, Retry (restart this stage), Sound and Quit.
- **SOUND** opens the sound settings: on/off, volume, music, effects and a test sound.
- **iPhone tip:** in Safari, Share → Add to Home Screen plays it full screen like an app.
