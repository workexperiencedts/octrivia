# Octrivia

A one-file pixel-art arcade trivia game. Play it free in your browser:
**https://workexperiencedts.github.io/octrivia/**

Guess which **country** the octopus is hiding in: 51 countries in Chad Mode (landmarks, food, flags, sport) and 28 in Demon Time (volcanoes, deserts and heat records), each with an easy, medium and hard clue, dealt in a random order. Works on computers, phones and iPads. Single-player only in this copy.

- **Phones and iPads:** there is no SHOOT button. Tap the screen to start and carry on, and tap an answer (or a barrel) to shoot it. Upright, the clue and a big button per barrel sit under the screen; sideways, the screen fills the whole height.
- **Held sideways / computer:** tap or click a barrel (or its name sign) to shoot it. On a keyboard, keys 1-8 pick a barrel.
- **PAUSE** opens a menu with Resume, Retry (restart this stage), Sound and Quit.
- **SOUND** opens the sound settings: on/off, volume, music, effects and a test sound.
- **iPhone tip:** in Safari, Share → Add to Home Screen plays it full screen like an app.
